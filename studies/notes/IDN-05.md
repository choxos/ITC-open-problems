**Study `studies/IDN-05-shared-modifier-check-power`, run and decided against a rule
registered before the run.** Six-study networks, deployment-weighted over a displacement grid.

**Registered rule.** The check earns the reassurance it is read as giving if the upper 95%
confidence bound on P(material error | the check did not fire) is below 0.10, where material
error is a C-versus-A marginal risk difference wrong by more than 0.03 absolute risk.

**Result: the rule fails.** Upper bound **0.697** on realized error and 0.563 on systematic
error, against a 0.10 threshold.

**The qualification matters more than the verdict.** An oracle that knows which specification
is true, fitted to the same replicates, is materially wrong **0.639** of the time at the same
displacement. The check's excess over that oracle is **0.036**, and at displacements 0 and 0.5
the excess is negative. A perfect check would have failed this gate too: with a 0.03
absolute-risk threshold, the estimation error of a six-study network alone exceeds it in 0.46
to 0.58 of replicates when the assumption holds exactly. The registered threshold was
unreachable by any procedure, so this is evidence about what a six-study network can support,
not only about the check.

Mechanism claims: decoupling **confirmed** (conditional risk rises 0.296 while the pass rate
is flat in displacement); identification asymmetry **partly** confirmed (contraction gap
widens monotonically, clearing 0.20 in 5 of 8 strata); the two rules differ on the null
**confirmed** (type I gap 0.087); the two rules disagree **not clearly met** (0.107, 95% CI
[0.096, 0.118], against a 0.10 threshold).
